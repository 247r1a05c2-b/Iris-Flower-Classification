# Iris Flower Classification using K-Nearest Neighbors (KNN)

## 📌 Project Overview

This project is developed as part of the **KodBud AIML Internship – Task 2**. The objective is to classify iris flowers into three different species using Machine Learning classification techniques.

The model is trained on the famous Iris dataset and predicts whether a flower belongs to **Setosa**, **Versicolor**, or **Virginica** based on its sepal and petal measurements.

## 🎯 Objectives

- Load and analyze the Iris dataset
- Perform data preprocessing
- Train a K-Nearest Neighbors (KNN) classification model
- Predict flower species
- Evaluate model performance using Accuracy Score
- Visualize results using a Confusion Matrix

## 🌸 Iris Flower Species

1. Setosa
2. Versicolor
3. Virginica

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Iris-Flower-Classification.git
```

Move into the project directory:

```bash
cd Iris-Flower-Classification
```

Install required packages:

```bash
pip install -r requirements.txt
```

## ▶️ Running the Project

Execute the Python script:

```bash
python iris_classification.py
```
